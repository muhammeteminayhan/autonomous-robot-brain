# Öğrenme Notları (Türkçe)

Bu klasör, projeyi geliştirirken öğrenilen konuların **Türkçe** notlarını
tutar. `docs/` altındaki diğer dosyalar İngilizce ve teknik referans
niteliğindedir; buradakiler ise "bunu neden böyle yaptık, kafamda nasıl
oturttum" seviyesinde.

Her faz için bir dosya:

| Dosya | Faz | Konu |
|---|---|---|
| `phase-00-ortam-ve-mimari.md` | 0 | Ortam kurulumu, repo mimarisi, açı normalizasyonu, SE(2) |
| `phase-01-simulasyon.md` | 1 | URDF, Gazebo, TF ağacı, topic grafiği |
| `phase-02-sensorler.md` | 2 | Gürültü modelleri, bias, random walk |
| `phase-03-odometri.md` | 3 | Diferansiyel sürüş kinematiği, dead reckoning |
| `phase-04-ekf.md` | 4 | Kalman filtresi, Jacobian, kovaryans |
| `phase-05-degerlendirme.md` | 5 | RMSE, hata metrikleri |
| `phase-06-haritalama.md` | 6 | Occupancy grid, log-odds, ray casting |
| `phase-07-planlama.md` | 7 | A*, Dijkstra, heuristic admissibility |
| `phase-08-lokal-kacinma.md` | 8 | DWA, velocity space |
| `phase-09-kontrol.md` | 9 | PID, kararlılık, anti-windup |
| `phase-10-ariza-enjeksiyonu.md` | 10 | Fault injection, filtre dayanıklılığı |
| `phase-11-benchmark.md` | 11 | Deney tasarımı, sonuç yorumlama |
